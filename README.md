# Tamil Fake News Detection 

Detects whether a **Tamil news headline** is Real or Fake using classical ML models
(TF-IDF + Logistic Regression / Naive Bayes / SVM / Random Forest / Decision Tree / XGBoost),
with predictions explained using **LIME** and **SHAP**, and deployed as a **Streamlit** app.

## Files

| File | Purpose |
|---|---|
| `Tamil Fake News Detection.ipynb` | Main Colab notebook — the full project (EDA → modelling → evaluation → LIME/SHAP → save model) |
| `app.py` | Streamlit web app (generated by the notebook) |
| `requirements.txt` | Python dependencies for running the Streamlit app locally |
| `Tamil-News-Headlines.csv` | Dataset (5,226 Tamil headlines, labelled Real/Fake) |

## How to run

### 1. Run the notebook (Google Colab — recommended)
1. Open [Google Colab](https://colab.research.google.com) → **File → Upload notebook** → select `Tamil_Fake_News_Detection_MiniProject.ipynb`.
2. Run the cells top to bottom (**Runtime → Run all**).
3. When prompted in the "Load Dataset" cell, upload `Tamil-News-Headlines.csv`.
4. The notebook installs its own dependencies (`lime`, `shap`, `wordcloud`, `xgboost`, `streamlit`, `pyngrok`) in the first cell.
5. Running the whole notebook produces:
   - EDA plots (class balance, category breakdown, word clouds, word frequency charts)
   - A comparison table + bar chart of 6 ML models by accuracy/precision/recall/F1
   - Confusion matrices for every model
   - LIME and SHAP explanations for sample headlines
   - A saved model file `tamil_fake_news_pipeline.pkl`
   - A generated `app.py` (Streamlit app)

### 2. Run the Streamlit app

**Locally** (after downloading `app.py` and `tamil_fake_news_pipeline.pkl` from the notebook run):
```bash
pip install -r requirements.txt
streamlit run app.py
```

**From Colab** (no local setup): use the final `pyngrok` cell in the notebook — paste a free
[ngrok](https://ngrok.com) authtoken and it prints a public URL for the running app.

## Notes on the approach

- **Text cleaning:** headlines are stripped of URLs, English words/digits, and punctuation,
  keeping only Tamil Unicode characters (U+0B80–U+0BFF).
- **Tokenization:** scikit-learn's default tokenizer breaks Tamil combining vowel signs away
  from their base consonant. `TfidfVectorizer(token_pattern=r'\S+')` is used instead, which
  also keeps the vectorizer picklable for deployment.
- **Best model:** typically Logistic Regression or Linear SVM reach ~91–92% test accuracy on
  this dataset; the notebook automatically picks the highest-accuracy model and calibrates it
  for probability output if needed (e.g. for `LinearSVC`).
- **Explainability:** LIME perturbs/removes words from a single headline to see which ones
  flip the prediction; SHAP computes per-word Shapley contribution values for a more
  theoretically grounded explanation. Both are shown in the notebook, and LIME is embedded
  live in the Streamlit app.

## Possible extensions
- Swap TF-IDF for Tamil-aware transformer embeddings (IndicBERT / MuRIL / MahaBERT-Tamil).
- Use the `English Version` column as an auxiliary feature or for cross-lingual comparison.
- Add stemming or a larger curated Tamil stopword list.
- Track experiments with MLflow; add cross-validation instead of a single train/test split.
